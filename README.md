# 飞书员工-薪酬-财务系统集成方案

## 项目概述
本项目旨在通过飞书开放平台集成员工管理、薪酬核算和财务管理三大系统，实现数据互通和流程自动化。

## 技术栈
- **前端**: Vue3 + Vite + Axios
- **后端**: Springboot + MyBatis
- **数据存储**: MySQL 8.x, Redis 6.x, MariaDB 11.1.2
- **接口**: 飞书开放平台

## 系统模块
1. **员工系统**: 基于飞书多维表格和云函数构建的组织架构引擎
2. **薪酬系统**: 动态规则引擎支持200+计算因子配置
3. **财务系统**: 报销OCR识别模块和预算控制算法
